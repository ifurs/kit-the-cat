# Як писати пригоди Kit the Cat

Довідник ключів і словників — [DSL.md](DSL.md) (генерується з коду). Тут — **як** писати так, щоб було смішно,
по-українськи і не ламало баланс. Перед комітом: чекліст у кінці.

## 1. Дух гри: українська реальність, доведена до абсурду

Пет живе нашим життям, тільки трохи гірше. Найкраще працюють впізнавані дрібниці, які кожен у чаті переживав сам:

| Тема | Що можна обіграти |
|---|---|
| Побут | хрущовка, ОСББ і його голова, сусід з перфоратором о 8:00 у суботу, ліфт, що застряг, бойлер, павербанк |
| Відключення | графіки світла, генератор на весь під'їзд, «світло дали — біжи прати», свічки й термос |
| Держава | ЦНАП, черга з номерками, «Дія», довідка про довідку, податкова, ТЦК (обережно — див. §3) |
| Транспорт | маршрутка («на зупинці!»), Укрзалізниця й Інтерсіті о 5:40, таксі з рейтингом 4.2, самокати |
| Магазини | АТБ і акції, «Сільпо» для багатих, Нова пошта (посилка з Китаю, «відділення №1 переповнене»), Розетка, OLX |
| Родина | бабуся, яка «ти схуд, їж», кум, хрещена, дача з картоплею, весілля на 200 гостей, кредит на айфон |
| Робота | айтішник на мітингах, блогер з 12 підписниками, кур'єр, депутат з тендерами, нічний охоронець |
| Свята | Новий рік з олів'є, Різдво й колядки, Андрія з ворожінням, Великдень і паска, Купала, День Незалежності |
| Культура | Євробачення, «Квартал»-стиль жартів НЕ потрібен — краще мемні фрази чатів, пісні на весіллі, «Червона рута» |

Принципи гумору:
- **Конкретика смішніша за загальне.** Не «пет пішов у магазин», а «{name} пішов в АТБ по хліб і повернувся з
  трьома пачками акційного печива й дриллю».
- **Чорний гумор — так, жорстокість — ні.** Пет може вдаритися струмом і почати світитися; не може страждати
  реалістично. Смерті петів — мультяшні («помер від сміху на корпоративі» — так; реальні знаменитості в причинах смерті — ні).
- **Ескалація.** Звичайна ситуація → абсурдний поворот → наслідок, який пет носить на собі (річ, ген, прапорець).
- **Наслідки видно.** Найкращі пригоди змінюють спрайт (`item=`, `gene=`, `mutate=`, `role=`) або відкривають
  ланцюжок (`flag=`). Гравці пам'ятають «той раз, коли мій лис став кіборгом після ЦНАПу».

## 2. Мова

- Сучасна українська, жива розмовна. **Без русизмів і суржику** (якщо це не навмисний жарт персонажа):
  «будь ласка» (не «пожалуйста»), «вирішувати» (не «рішати»), «наступний» (не «слідуючий»), «захід» (не «мероприятие»),
  «вибачте» (не «ізвініть»), «зачекай» (не «подожди»), «отримати» (не «получити»), «квиток» (не «білет»).
- Апостроф — прямий `'`: «пам'ять», «м'ясо», «з'їв», «під'їзд», «кур'єр». Ґ там, де треба: «ґудзик», «ґанок».
- Звертання до гравця — на «ти». Пет — «{name}»; рід у тексті нейтралізуй, де можна («{name} з'їв» — ок, пети
  мають чоловічий рід за замовчуванням; уникай фраз, що ламаються для «Лисички» — краще дієслово в минулому часі
  перебудуй: «{name} вирішує…», «у {name} тепер…»).
- Кнопки (`ch("…")`) ≤ 40 символів, коротко й дієслівно: «Віддати в садочок», «Ставка на все».
- Текст події ≤ 450 символів (підпис до фото ≤ 1024 разом з усім іншим). Результат — 1–2 речення.

## 3. Межі (не обговорюються)

- **Ніякої ненависті чи висміювання за ідентичністю**: етнічність (зокрема роми), раса, релігія, орієнтація,
  гендерна ідентичність, інвалідність, зовнішність, яку не обирають. Висміюємо поведінку й ситуації, не людей.
- **Ніяких інструкцій чи заохочення** самоушкодження, розладів харчування, реального насильства, наркотиків.
  «Пиво з кумом» — ок; деталізоване вживання речовин — ні.
- **Війна**: з повагою до захисників, ветеранів, загиблих, волонтерів і цивільних. Жодних жартів про реальні
  втрати, полон, катування, конкретні трагедії. Ворога й пропаганду можна висміювати; не дегуманізуй людей за
  етнічністю. Волонтерство, донати, «бронік для кота» — так, з теплом.
- **Реальні люди**: приватних — ніколи; публічних — лише як очевидна, не наклепницька сатира (краще взагалі без імен).
- **Романтика** лише з підліткового віку (закоханість), пари й діти — дорослі. Рушій це забезпечує
  (`ROMANCE_MIN_STAGE`), але і текст не повинен натякати на інше.

## 4. Анатомія пригоди

```python
ev("cnap_queue", "{name} прийшов у ЦНАП по довідку. Номерок 347, на табло — 12.",
   ch("Чекати чесно", o("Через 6 годин отримав довідку… не ту.", mood=-15, int=2),
      o("Познайомився в черзі з бабусею — тепер вона його хрещена.", love=3, cha=2, w=0.5), auto="love"),
   ch("Пройти «я тільки спитати»", o("Спрацювало! Черга проводжала поглядом.", toxic=2, cha=3),
      check=("cha", 25), fail=[o("Охоронець провів {name} до кінця черги з почестями.", mood=-10, toxic=1)],
      auto="toxic"),
   ch("Записатися в «Дії»", o("Електронна черга на березень 2031-го.", mood=-5, int=1)),
   req=dict(stage=(3, 4)), bg="office", aff=("patriot",)),
```

- **id** — унікальний, англійською, з префіксом теми (`cnap_`, `job_it_`, `sp_fox_`, `tw_`, `soc_`, `role_vampire_`).
- **2–4 варіанти**, кожен — інший характер. Позначай `auto="<риса>"`: так пет сам обирає «в характері», коли
  власник не відповів. Зараз найменше варіантів для **glutton** (обжора) — пиши їх (`content_stats.py --gaps`).
- **Кілька результатів** з вагами (`w=`) — для непередбачуваності. Рідкісний результат: `w=0.2–0.35`.
- **Перевірка** `check=("skill", diff)` + `fail=[…]`: провал має бути смішним, не просто «нічого не сталося».
- **Вимоги** `req=` на подію і на окремий варіант (`ch(..., req=dict(money=300))` — дорогий варіант зникає для бідних).
- `once=True` — подія раз за життя (садочок, випускний). `bg=` — фон сцени. `aff=` — риси, що роблять подію частішою.

### Складність перевірок

Шанс = `0.5 + (навичка + удача·0.15 + (рівень−1)·1.5 − diff·k) / 50`, де k = 0.6 малюк, 0.8 підліток, 1.0 дорослий;
межі 20–95 %. Типовий пет: малюк навичка ~11, підліток ~20, дорослий ~30, старий ~35.

| diff | Малюк | Підліток | Дорослий | Старий | Для чого |
|---|---|---|---|---|---|
| 10 | 63 % | 82 % | 95 % | 95 % | буденне |
| 25 | 45 % | 57 % | 75 % | 92 % | помітне зусилля |
| 40 | 27 % | 34 % | 45 % | 62 % | ризик |
| 55+ | 20 % | 20 % | 20 % | 32 % | легендарне (кар'єрні вершини, президентство) |

(Цифри — для перевірки не удачею; рахує `typical_chance()` у `scripts/content_stats.py`.)

`content_stats.py` попереджає, якщо типовий пет наймолодшого можливого віку має < 30 %. Для фіналів ланцюжків
це нормально (рідкісна перемога = історія), але дай гідний провал.

### Масштаб наслідків

| Ефект | Дрібно | Помітно | Велике | Не більше |
|---|---|---|---|---|
| стати (`mood`, `health`) | ±5 | ±15 | ±30 | ±60 (не вбивай статами — є `die=`) |
| життєві стати (`fame`, `auth`, `blat`, `fin`, `attr`) | +3 | +8 | +15 | +25 |
| навички (`int`…) | +1 | +3 | +6 | +10 |
| риси (`toxic`…) | +1 | +2 | +4 | +6 |
| гроші | ±50 | ±300 | ±2000 | ±10000 або `money_mult` |
| `jail` / `hospital` | 6 | 24 | 48 | 96 год |
| `lifespan` | ±2 | ±5 | ±15 | ±35 років |

Гроші: зарплата 60–600 ₴/день, побут дорослого 25–600 ₴/день (залежить від рівня статків); медіана гаманця
живих петів у симуляції ~3000 ₴. Подія, що дає +5000, має бути рідкісною або платною (ризик).
`hunger`/`clean`/`energy` тепер автоматичні (побут) — у нових пригодах їх не чіпай.

### Час

Пет старіє за годинником (~75–90 років ≈ 30 реальних днів); самі рішення часу не забирають. Сюжет може
перескочити роки лише як наслідок: `o("Прокинувся через п'ять років…", time="5y")` — кома, кріосон, вирок.

### Наслідки: минуле повертається (головне правило)

Рішення мають впливати на наступні події. Якщо вибір міг би мати значення через роки, додай у його результати `then=("fu_<id>", "2y")` і напиши
подію-наслідок у `content/consequences.py` з `followup=True`. Вона ніколи не випадає випадково, лише як наслідок,
і її текст нагадує про той вибір: «Пам'ятаєш, як {name} назвав шахраям три цифри з картки?…». Добрі наслідки —
неочевидні: дитина з укриття виросла лікаркою; кум, якому ти поклав 5000, кличе в хрещені; той велосипед
з «шухеру» вкрали в майбутнього слідчого.

**Арки** (`content/arcs*.py`) — найкращий формат: подія-корінь, де кожен вибір веде до *свого* наслідку,
а наслідок інколи — до наступного (малюнок на шпалерах → виставка → резиденція у Львові). Пиши нові арки,
а не поодинокі події: так гравець бачить, що його вибір щось змінив.

### Життєві стати й рівні

📈 `fame` популярність · 🕶 `auth` авторитет · 🤝 `blat` блат · 📊 `fin` фінграмотність · ✨ `attr` привабливість
(0–100, рівні на 20/45/70/90) і 💰 рівні статків. Назви рівнів — у [DSL.md](DSL.md).
- Риси й навички в результатах уже «відлунюють» у статах (тусовки → популярність, токсичність → авторитет,
  розум → фінграмотність, харизма → привабливість і блат), тож пиши стати явно лише там, де це суть події.
- `req=dict(tier={"fame": 2})` відкриває події рівня: ризики слави (хейтери, папараці), авторитету (облави,
  «пропозиції»), блату (тендери, НАБУ). Кожен високий рівень має і вигоду, і ціну.
- Привабливість — це стиль, доглянутість і шарм, які пет заробляє. Ніколи не висміюй зовнішність, яку не обирають.
- Казино — це сатира: фінграмотність і вчасна зупинка мають бути вигідними; не роби залежність привабливою.

### Смерть і ролі

- `die=` — лише рідко (`w ≤ 0.3`), після явно небезпечного вибору, з абсурдною причиною. Ціль балансу:
  ≤ 15 % смертей — від подій (`balance.py`). Причина — фраза після «помер…/пішов…».
- Ролі (`role="vampire"`) — події-повороти; `twist=True` для гучного оголошення. Кожна роль має «лікування»
  десь у контенті (`role=""`). Пасивки ролей — у [DSL.md](DSL.md).

## 5. Ланцюжки (квести)

`flag={"crime": 1}` → наступна подія `req=dict(flag={"crime": 1})` → … → фінал з `unflag="crime"`.
- Кожне значення прапорця, якого вимагає якась подія, хтось має виставляти — інакше тупик
  (`content_stats.py --strict` це ловить).
- Дай вихід з ланцюжка на кожному кроці (кнопка «зав'язати»).
- Ланцюжки з роботою — через `job=`; дорослим. Ланцюжки з тюрмою — `jail=`, вихід `free=True`.

## 6. Соціальні пригоди

`social=True`: друга тварина з чату — `{other}`, її власник — `{other_owner}`. Ефекти для неї — `other={…}`,
стосунки — `rel=`, `status=`. Діти — `baby=True` лише для пари дорослих (`req=dict(status=["partner"])`).
`{other}` поза social — помилка.

## 7. Сезони

`req=dict(season="winter")`, свято (`"newyear"`, `"andriy"`, `"easter"`, `"kupala"`, `"independence"`…) або
номери місяців. Дата — реальна київська. Сезонні події роблять гру «живою» в певні тижні — пиши по 2–3 на свято.

## 8. Робочий процес

```bash
uv run python scripts/content_stats.py --gaps     # що писати (тонкі місця)
# … пишеш у content/<тема>.py …
uv run python scripts/content_gate.py --quick     # усі автоматичні перевірки, зокрема українська (ua_lint)
# … рецензія агента content-reviewer: природність мови, межі, гумор …
uv run python scripts/content_gate.py             # + баланс у симуляції
uv run kit-the-cat                                # зіграти в пісочниці
```

Нова механіка, якої немає в DSL? Спочатку ключ у `dsl.KNOWN_FX`/`KNOWN_REQ` + документація в докстрінгу dsl.py +
реалізація в `engine.Pet.apply`/`meets` + тест, потім `scripts/gen_dsl_docs.py`.

## Чекліст пригоди

- [ ] id унікальний, з префіксом теми; ≤ 450 символів тексту; кнопки ≤ 40
- [ ] українська без русизмів; апострофи `'`; рід не ламається для будь-якого пета
- [ ] межі §3: нікого не висміюємо за ідентичністю; війна — з повагою; реальних людей немає
- [ ] 2–4 різні за характером варіанти з `auto=`; провал перевірки — смішний
- [ ] наслідки в межах таблиці; велике — рідкісне або ризиковане
- [ ] вибір, що мав би наслідки, має `then=` і подію-наслідок, яка нагадує про нього
- [ ] `content_gate.py` зелений, `ua_lint` без попереджень у нових текстах; рецензія content-reviewer врахована
- [ ] `req=` відповідає змісту (робота → дорослий, романтика → підліток+)
- [ ] validate + content_stats --strict + pytest зелені; зіграно в пісочниці
