## Uniqueness in a 200-pet chat

Each pet is created with `unique_genome(species, others, rng)` against all pets already in the chat; some runs mix in children bred from two chat members (`parents=`).

| run | breed share | min pair dist | avg pair dist | min nearest | avg nearest | nearest < 4 | duplicate looks |
|---|---:|---:|---:|---:|---:|---:|---:|
| seed 1 | 0% | 4.00 | 10.33 | 4.00 | 5.15 | 0 | **0** |
| seed 2 | 0% | 4.00 | 10.33 | 4.00 | 5.23 | 0 | **0** |
| seed 3 | 30% | 4.00 | 10.25 | 4.00 | 5.02 | 0 | **0** |
| seed 4 | 60% | 4.00 | 9.89 | 4.00 | 4.81 | 0 | **0** |

`distance` = number of differing visible genes (+species) + up to 2.0 for colour difference; duplicate look = same `visible_key` (species + all 10 visible genes). `unique_genome` guarantees 0 duplicates.
